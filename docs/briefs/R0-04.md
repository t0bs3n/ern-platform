# R0-04 Styles and page frame

## What was built
- `public/css/ern.css`: `docs/mockup/theme.css` followed by `docs/mockup/app.css`, with a short block of platform additions at the end. Changes to the mockup parts: the Google Fonts import is removed (no external fonts), and image addresses point to `public/img/`.
- `public/img/`: the mockup's images.
- `resources/views/layouts/site.blade.php`: the frame for every page. It has a skip link, the sticky header with the logo, the eight navigation items, the saved-library icon, the "Member area" button, the mobile menu and the footer (`resources/views/partials/footer.blade.php`) with its columns, contact addresses and social links.
- `config/ern.php`: the five social profiles (X, LinkedIn, Twitch, Discord, YouTube), taken from the published mockup.
- `public/js/ern.js`: a small script that turns the menu button into a toggle (Escape closes the menu) and adds the line under the header when the page is scrolled.
- The mobile menu opens without JavaScript too. The menu button is a link to `#mobile-menu`, and the stylesheet opens the menu when it is the target.
- The current navigation item is marked (highlighted, with `aria-current="page"`). Each page passes its key, for example `nav => 'news'`.
- A placeholder start page with the hero title and text from the mockup, and a 404 page in the same frame.
- Left out as the task says: the mock bar, the Ernie button, "About this mockup". The footer's "Admin area" link comes with R0-08, for users with an admin role only.

## How to see it
`php artisan serve`, then open http://localhost:8000 and any unknown address, such as http://localhost:8000/xyz. Make the window narrow to see the mobile menu.

## What was tested
- The start page answers 200 and shows every navigation label, the skip link, the saved library, the member button, the mobile menu and the footer.
- No mock bar, no Ernie, no "About this mockup", no "Admin area".
- The page loads no script, stylesheet, image or frame from another site.
- The social links are shown.
- The current item is marked in the desktop and mobile navigation.
- An unknown address answers 404 inside the frame.
- The stylesheet has no external font import.
- By hand, with a headless browser: desktop at 1280 pixels, phone at 375 pixels with and without JavaScript. The menu opens in both cases and there is no sideways scrolling.

## What was not tested
- Real phones, keyboard-only use and 200% zoom. These come in R1-20.
- The navigation links lead to pages that do not exist yet, so they answer 404 for now.

## Good to know
- Fonts: Inter and Outfit are not loaded from Google, by decision. Visitors who have them installed see them; everyone else sees the system font. To show them to everyone, the font files would have to be stored on our own server. That needs Tobi's agreement and a check of the font licences (both are open fonts).
- Footer headings are h2 rather than the mockup's h4, so the order of headings is correct for screen readers. They look the same.

- Removed two unused files from the Laravel starter: the welcome page (`resources/views/welcome.blade.php`, replaced by the start page) and the example feature test (replaced by `tests/Feature/PageFrameTest.php`).
- The social addresses are not in `docs/mockup/` (the footer there has only a placeholder). They come from the footer of the published mockup that the board approved. Tobi, please check that the X and LinkedIn addresses are still right: `x.com/esportsresnet` and `linkedin.com/company/esportsresearchnetwork`.
- Without JavaScript, the opened mobile menu closes when a link in it is followed. It has no separate close button.
