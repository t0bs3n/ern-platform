# R1-05 Code of Conduct, Imprint, Privacy

## What was built
- **`/code-of-conduct`**: the Code of Conduct (version 1.1) from the mockup, with the "On this page" jump links, built from the page's own `##` headings, so they follow any change an editor makes. It has the box "Something happened?" with "Report a concern".
- **`/imprint`**: the association's details and its legal representative.
- **`/privacy`**: a clear placeholder. It says the board is preparing the policy, links to the current website's policy, and lists its sections.
- All three are pages that editors change in the Content tab. They are seeded by `ContentSeeder`, which never overwrites edits.
- The footer now links "Imprint" and "Privacy Policy".
- **The live check** `php artisan ern:check-launch` refuses (exit code 1, with a plain message) while the privacy page is missing or still holds the placeholder text. R0-10's task text now says that the live upload workflow runs it first and stops if it fails. That workflow does not exist yet.
- The Markdown converter can now give `##` headings an anchor (`#sec-…`). The Code of Conduct uses it, and other long pages can too.

## How to see it
`php artisan migrate:fresh --seed`, `php artisan serve`, then /code-of-conduct, /imprint and /privacy. Run `php artisan ern:check-launch` to see the refusal.
