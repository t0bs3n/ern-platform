# R0-03 Quality gate

## What was built
- `composer check`: runs Laravel Pint in test mode (code style), then all tests. It stops at the first failure.
- `composer fix`: lets Pint correct the code style.
- The tests use an in-memory SQLite database (set in `phpunit.xml`), so they need nothing installed and leave nothing behind.
- `.github/workflows/check.yml`: GitHub runs `composer check` on PHP 8.3 for every pull request, and on main after each merge.

## For Tobi: protect the main branch (once, about 3 minutes)
Do this after this pull request is merged and the check has run once, so that GitHub knows its name.

1. On GitHub, open the repository, then **Settings**, then **Rules**, then **Rulesets**, and choose **New ruleset**, then **New branch ruleset**. Name it "main", and under target branches choose **Include default branch**.
2. Tick **Require a pull request before merging** and leave **Required approvals** at 0, because you cannot approve your own pull requests. Tick **Require status checks to pass**. Under the status checks, press **Add checks** and choose **composer check**.
3. Tick **Block force pushes**, set **Enforcement status** to **Active**, and press **Create** (or **Save**).

This needs a public repository or a paid GitHub plan (Pro or Team). On a private repository with the free plan, GitHub shows the rules but does not enforce them.

From then on, the "Merge" button stays grey until the check shows a green tick.
