# R0-02 Create the application

## What was built
- A fresh Laravel 13.44.1 application in the repository root. It was created in a separate folder and moved in, so `CLAUDE.md`, `README.md`, `docs/` and `.claude/` are unchanged.
- Application name "Esports Research Network". SQLite locally.
- Node scaffolding removed: no `package.json`, no Vite configuration, no `resources/css` or `resources/js`, no Vite directive. The start page is a plain placeholder until R0-04.
- `.env.example` for local use (no secrets) and `.env.staging.example` with empty values for the server.
- `.gitignore` covers `.env`, `.env.staging`, `vendor/` and the SQLite file.
- The Composer script `setup` no longer runs npm. `composer dev` starts `php artisan serve`.
- The Laravel version is recorded in `docs/DECISIONS.md`.

Not taken over from the Laravel starter: its own `CLAUDE.md` and `AGENTS.md`, its GitHub workflows, `.styleci.yml` and `.npmrc`. They belong to the Laravel project, not to us.

## How to see it
```
composer setup
php artisan serve
```
Then open http://localhost:8000. The page shows the name and "The platform is being built."

## What was tested
- The two example tests shipped with Laravel pass.
- `php artisan serve` answers with the placeholder page.
- `composer validate` passes.

## What was not tested
- The desktop app on Tobi's Mac.
- MySQL. The server template is set up for it, but nothing has run against MySQL yet.

## Good to know
In Claude Code in the browser, GitHub refuses Composer's quick package downloads, so `composer install` clones every package with git instead. That works but takes several minutes. `composer install --prefer-source` skips the failing attempts and is faster there.
