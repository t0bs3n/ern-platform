## Setup script and session-start hook
Not added. PHP and Composer come pre-installed in Claude Code in the browser, so nothing has to be installed at the start of a session. The Composer packages (`vendor/`) are not in the repository, so each new session runs `composer install` once before working. If that turns out to be slow or forgotten, a session-start hook can do it later.
